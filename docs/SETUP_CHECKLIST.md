# Setup checklist

Things only I can do: installs, accounts, keys, purchases, and devices. Each names the card that needs it, so nothing here has to happen before its card comes up. Keys and passwords go where the card says (an env file or the secret store), never into a chat.

## Before the first card

- [ ] PresentMon 2.6.0 console app: download `PresentMon-2.6.0-x64.exe` (the console app, not the `.msi`) from https://github.com/GameTechDev/PresentMon/releases/tag/v2.6.0 into the repo's `tools/` folder. (needed by P0-01)
- [ ] A copy of my Fabulously Optimized 26.2 instance, made with Prism's own Copy button. The real instance is never used for testing. (needed by P0-01)
- [ ] A copy of my Fabulously Optimized 26.3 instance, made the same way. If I don't have a FO 26.3 instance yet, make one first. (needed by P0-01)
- [x] Membership in Windows' "Performance Log Users" group, so PresentMon runs without admin. Already a member (checked 2026-10-05). (needed by P0-01)
- [ ] Laptop plugged in, with the MSI Center mode I want to benchmark in. (needed by P0-01 and every real run)
