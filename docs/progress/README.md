# Progress notes

One note per card, `docs/progress/<card-id>.md`, written by the session that runs the card as it goes, so any session can continue it. The format is in the card skill's `templates/progress-note.md`. `loose-ends.md` holds follow-ups that belong to no card, one line each; remove a line once it's done.

`PROGRESS.md` at the repo root is the log from before this workflow (up to 2026-10-06).
