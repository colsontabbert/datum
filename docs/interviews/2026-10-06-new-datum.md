## Firm from the brief

All taken as defaults in round 1 (2026-10-06). Numbers match the round 1 list.

3. Datapack (Tier 0) is later work, for older versions and other loaders.
4. Check every new dependency is actively maintained before adding it.
5. Only frontend: a generated static `report.html` in the Tactile Web design language.
6. CI: ruff + pytest, probe build per Minecraft version (running already).
7. colsontabbert-python-lib: ask when work reaches config loading and logging.
8. MIT, public repo `datum`, auto-push (done).
9. Windows only for v1.
10. MSI Vector A16 HX laptop (Ryzen 9 8940HX, RTX 5070 Ti laptop, 16 GB). Every run proves it used the RTX card.
11. Prism Launcher; Minecraft 26.2 and 26.3, Fabric.
12. FO 14.1.0 (26.2), FO 15.0.0-alpha (26.3). Usual instance = FO + extra mods; the runner reads the mod list from the instance.
13. Graphics API is a sweep axis.
14. Pipeline: clone instance, apply settings and mods, fresh world, launch through Prism, record, restore, repeat, analyze.
15. Keep as much as possible outside the game.
16. PresentMon by process ID; GPU Busy labels scenes CPU-bound or GPU-bound.
17. JFR on every run with the same settings.
18. nvidia-smi logging every run.
19. Per-run system snapshot (GPU, API, driver, AC power, Java, JVM args, versions, mod list with hashes, config hashes).
20. The game log proves API and GPU; mismatches thrown out; options.txt compared before and after each run.
21. Probe: smooth camera path, capture markers, tick time, entity counts, loaded chunks, clean quit. Chunk rebuild counts optional.
22. One frozen golden world per version and worldgen mod set, pregenerated, fresh copy per run; DH pregen then distant generation off.
24. Settings: options.txt, Sodium, Iris, DH config, JVM heap; backup and restore, also after crashes.
25. Mods disabled by renaming to `.jar.disabled`, never deleted; never disable a library alone.
26. Only cloned benchmark instances, never the real ones.
27. A/A check starts every session.
28. Warmup: skip the start of each run, discard the first launch, wait for a target temperature between runs (exact numbers rough).
29. 5 runs per config by default, 4 minimum.
30. Counterbalanced ABBA order.
31. Conditions: plugged in, same MSI Center mode, same resolution, vsync off, FPS cap off; runner checks and warns.
32. Metrics list as in the brief.
33. Rank-based statistics (Hodges-Lehmann + exact Mann-Whitney); "no measurable difference" inside the noise floor.
34. No composite score.
35. Throw out and rerun: wrong GPU or API, battery, crash, missing markers, heavy throttling ("heavy" threshold rough).
36. ETA shown before every session.
37. Experiment priority: A/A, settings sweep, pack comparison, mod testing, version comparison.
39. Vulkan tested for a mod set only once every mod in it is confirmed to work on Vulkan; otherwise the report says why.
40. Pack comparison: vanilla vs FO vs FO + my mods vs a big stress pack.
41. Leave-one-out mod testing for client, performance, and visual mods; group toggles first, then narrow.
43. `results/<session-id>/` layout and findings tone from the brief.
44. Milestone order: M0 proof, M1 runner skeleton, M2 probe, M3 honest numbers, M4 settings sweep, M5 mod testing, M6 HTML report, then later work.
45. Not in v1: in-game GUI, auto-applying settings, crowdsourced database, Mac or Linux, server benchmarking.

### M1 runner skeleton (round 2)

- 2026-10-06 Q: How it starts? A: default: `datum run <plan.toml>` and `datum check` (Prism found, PresentMon present, nvidia-smi works, on AC; launches nothing).
- 2026-10-06 Q: Datum's own settings? A: default: `datum.local.toml` in the repo, git-ignored; committed `datum.example.toml`; Prism location guessed first, file only needed when the guess is wrong.
- 2026-10-06 Q: colsontabbert-python-lib? A: default: don't add it. Use the built-in `tomllib` and `logging`. Reasons: the lib is private and Datum is public (CI would need a token), and its config module reads env vars, not TOML.
- 2026-10-06 Q: M1 plan file contents? A: default: source instance name, a save to load, run length, number of runs, one config (a list of options.txt values, such as the graphics API). Several configs come in M4.
- 2026-10-06 Q: Clones? A: default: one clone per session, `datum-bench-<session-id>`, settings reset before every run, fresh save copy every run. Deleted at session end, only folders Datum created (marker file). `--keep` keeps it.
- 2026-10-06 Q: Which world before M2? A: default: a save named in the plan, from the source instance; only ever copied, never written.
- 2026-10-06 Q: When a run starts and stops? A: default: record once the log shows the world loaded; 15 s warmup, then the run length (60 s default); save JFR with `jcmd`, then close the game.
- 2026-10-06 Q: Bad runs in M1? A: default: wrong GPU, wrong API, options.txt changed by the game, battery, crash: marked invalid with a reason, files kept. Automatic reruns in M3.
- 2026-10-06 Q: Prism already open? A: default: refuse to start and ask me to close it; Datum opens and closes Prism itself per run.
- 2026-10-06 Q: Hangs? A: default: world not loaded within 3 minutes = run failed; two failures in a row stop the session.
- 2026-10-06 Q: What I see? A: default: one plain terminal line per step, a simple time estimate at the start, everything also in `datum.log` in the session folder.
- 2026-10-06 Q: Ctrl+C? A: default: close the game, stop recording, clean up, keep finished runs, mark the session incomplete. No resume in v1 (parked).
- 2026-10-06 Q: Sleep? A: default: keep Windows awake and the screen on during a session, then restore.
- 2026-10-06 Q: Using the laptop during a session? A: default: M1 warns at the start; focus-loss detection comes in M3.
- 2026-10-06 Q: Results location? A: default: `results/<session-id>/` in the repo, git-ignored; ID like `2026-10-06_1432_<plan name>`.

### GUI (round 2, new)

- 2026-10-06 I want a small desktop GUI in the tkinter style of my Delta-RetroArch Synchronizer project, even though the brief left a GUI for "maybe later". The brief's "no in-game GUI" still stands. Details in round 3.
